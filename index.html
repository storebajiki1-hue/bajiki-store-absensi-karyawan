Panduan untuk Owner Perusahaan

  1. Buka Google Spreadsheet baru atau yang sudah Anda sediakan.
  2. Klik menu Extensions (Ekstensi) > Apps Script.
  3. Hapus seluruh kode bawaan di file Code.gs, lalu salin dan tempel (paste) seluruh isi file script Code.gs yang disediakan di aplikasi Android Anda.
  4. Pilih fungsi setupDatabase di panel atas Apps Script, lalu klik tombol Run (Jalankan). Berikan izin otorisasi spreadsheet jika diminta.
  5. Klik tombol Deploy (Terapkan) > New Deployment (Terapkan Baru) di bagian kanan atas.
  6. Pilih tipe Web App (Aplikasi Web). Atur "Execute as" ke Me (Saya) dan "Who has access" ke Anyone (Siapa saja).
  7. Klik Deploy, salin Web App URL yang dihasilkan, lalu masukkan URL tersebut ke setelan aplikasi Android Anda untuk mulai berkoneksi secara instan!
